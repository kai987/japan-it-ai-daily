### 1. 起動スクリプトが落ちても、デプロイは成功する

**原文：** https://zenn.dev/miyakona/articles/ec2-replacement-waits-for-user-data

**公開日時：** 2026-11-16 09:01:46 JST

VPNのAMIを更新した筆者は、CloudFormationの成功を見た後、接続できないことに気付きました。二台の新しいEC2では、メモリ不足で dnf が強制終了し、鍵の復元と WireGuard の起動に進んでいません。先に Elastic IP が移ったため、古い台が使えなくなりました。起動が落ち着いてから手で流し直すと、パッケージ導入と設定復元が通りました。

対策では、CreationPolicy で一台につき一件の成功通知を待ちます。シェルの終了時に SignalResource で成否を伝え、待機時間を PT15M に区切ります。EIPの関連付けには新しいインスタンスのIDを使うので、作成完了を待って切り替えます。userDataCausesReplacement を有効にするのは、変更した初期化処理を新しい台で動かすためです。補助として一時的なswapを用意し、必要なインストールは三回まで試します。

修正後の更新では、二台から通知が届いた後に固定IPが移り、接続先の設定も確認できました。ただし、実機の片側を故意に失敗させるテストは行っていません。同じスタックで片側が先に切り替わった場合、ロールバック時にもう一度IPを付け替えることがあります。初回作成には戻せる旧台がなく、成功通知の後の故障は通常の監視で追います。

**読む価値：** 新しい台への切り替えを、起動処理の結果に結び付ける方法が分かります。

### 2. Cloudflare Workers のテスト40項目を Node で動かす構成：D1 と R2 の代替

**原文：** https://zenn.dev/sakidori/articles/20261030-workers-test-d1-r2-fake-node

**公開日時：** 2026-11-16 06:14:48 JST

一つのWorkerにサービスを相乗りさせ、通知や動画の処理を共用すると、変更が別の入口にも届きます。筆者は維持できる件数に割り切り、デプロイ前に node:test から結合テスト30項目とブラウザ操作10項目を動かしています。ハンドラの大半はTypeScriptで、Workers固有の振る舞いに深く寄りかかる構成なら公式の環境も選択肢になります。

D1は prepare と bind を持つ代替へ差し替え、登録した正規表現で行を返しながらSQLと引数を記録します。同じ朝の登録を二度送って、同じ書き込みキーになったかを読めます。動画は20MBずつ送り、R2の代替で createMultipartUpload の後に来る uploadPart と complete、番号と etag の受け渡しを確かめます。

代替はSQLを実行しないため、検索条件の意味や索引を使うかどうかは本物のD1で調べます。実際にR2のバインディングが有効になる前にデプロイした例もありました。ブラウザ側は手元のEdgeで入力・保存までを確かめる範囲で、画面の比較や他のブラウザの互換性には別のテストが要ります。

**読む価値：** 代替の効く範囲がはっきりすると、デプロイ前に何を自動化するかを決めやすくなります。

### 3. Astro 5から7へ上げたら、Tailwindの1行でビルドが落ちた

**原文：** https://zenn.dev/a1221/articles/astro-7-upgrade-build-failures

**公開日時：** 2026-11-16 08:36:39 JST

Astro製の静的ツール集を5.16から7.4.12へ上げる作業です。既存のremarkとrehypeを使うため、Markdown処理は @astrojs/markdown-remark の unified を明示しました。新しいコレクションは glob loader で読み込みます。旧来のslugで記事を引く箇所は、idを渡す一つの取得関数にまとめました。レイアウトに二重で書かれた frontmatter の区切りも、48件のエラーを生んでいました。

ビルドでは lightningcss が、ソースの場所を示さずに圧縮を止めました。圧縮しないCSSを出すと、Tailwind v3 の @layer の中で .border が file:border のバリアントへ展開され、file-selector-button の後ろに first-of-type が残っていました。筆者はクラスに対する属性セレクターを使い、同じクラスへ当てながら展開を避けています。

検証では506ページを正規化して、ハッシュつきの名前などを除いたHTMLを突き合わせました。同じ日付の並びに差があり、idで順序を固定しています。主要六ページをテーマと幅の四条件で撮った画面には、暗色のスマホ版ホームで2.2%の差が残り、原因は未確認です。Tailwind 4 では暗色の差が5〜20%に広がったため、更新を切り分けました。

**読む価値：** 移行で表示順が揺れる理由や、圧縮前の出力からエラーを絞る手順が読めます。

### 4. 【100本ノック実測】和暦・漢数字・結合セル…日本の泥臭い業務データを最新LLM 3モデルに構造化させて見えた「現場の壁」

**原文：** https://zenn.dev/ai_nexus_jp/articles/dirty-jp-data-extraction-benchmark

**公開日時：** 2026-11-16 08:35:42 JST

和暦の発行日、漢数字の金額、結合セルのある帳票、口頭での注文訂正などを含む百問を筆者が作り、三モデルの出力を比較した報告です。Pydantic Strict で日付や明細の型をそろえ、迷う入力には is_ambiguous を使う仕組みでした。

三百件の構文検査はすべて通過しました。完全一致はモデル順に93%、90%、89%です。例えば発注日が期間の場合、正解では初日を issue_date としましたが、一部の回答は特定不能として null を返しました。見積もり依頼に書かれた希望額を、税抜小計へ入れるかどうかでも割れました。

正解の決め方が曖昧なままだと、単に点数を見るだけでは直す場所が分かりません。希望予算を別の項目に定義することも、業務上の判断になります。ただしこの実測は自作問題の結果です。会社ごとの帳票や実際の入力への適用では、和暦の変換、期間の採番、確定額と希望額の違いを先に決め、分類ごとに検証します。

**読む価値：** 見積依頼の予算や発行日を、現場が使える項目として扱う条件を考えられます。

### 5. 「止まっても書き出せる」から選んだ停止検知が、高負荷の夜にワーカーを落としていた話

**原文：** https://zenn.dev/itaraiguma/articles/faulthandler-stall-watchdog-segfault

**公開日時：** 2026-11-16 07:09:42 JST

メモリ1GB弱のVPSで、DevPickのuvicornワーカー二つとブログを動かしていた事例です。元の監視は faulthandler.dump_traceback_later を使い、一秒ごとに三秒後の予約をかけ直します。予約が途絶えるとCの監視スレッドが動くため、止まった側がGILを保持したときも記録を試みます。

11月14日夜の集中アクセスでは、50分でワーカーのSIGSEGVが五回ありました。調べられた三つのコアダンプでは、他スレッドのスタックを出している監視側で落ちていました。筆者は、読み取りと同時にフレームが更新される危険を指摘します。起動し直したワーカーがアプリのロードで約100MBを使うので、メモリが厳しいときには再起動も負荷になります。

置き換え後はGILを取って読み、出力を一ワーカー三回までに抑えます。止まった長さも、動き出したときにログへ残します。ただし、GILを離さない停止が30秒を超えれば、親に終了されるまで記録できない場合があります。同じ規模の負荷でSIGSEGVが減るかは、公開時点でまだ確かめられていません。

**読む価値：** 監視のための処理が、障害時にはどんな負担になるかを具体的に追えます。

### 1. 落ち着く（おちつく）｜N2

- 品詞：五段・自動詞
- 意味：騒ぎや変動が収まり、安定した状態になる。
- 連語：負荷が落ち着く / 事態が落ち着く
- 記事文脈：EC2では、起動時の負荷が下がるまで時間を置いています。
- 例文：アクセスが落ち着いてから、残りのデータを移します。
- 例文の意味：アクセスが安定してから、まだ移していないデータを移動します。
- ニュアンス：人の気持ちにも、負荷のような状況にも使います。

### 2. 区切る（くぎる）｜N2

- 品詞：五段・他動詞
- 意味：時間や文章に切れ目を入れ、まとまりを分ける。
- 連語：時間を区切る / 段落で区切る
- 記事文脈：待機の上限を設定し、次へ進むか失敗にするかを判断します。
- 例文：作業時間を三十分で区切り、終わらなければ担当者に知らせます。
- 例文の意味：三十分を作業の上限にして、それまでに終わらない場合は担当者へ連絡します。
- ニュアンス：一つの作業の区間や文の境界を決めるときに使います。

### 3. 寄りかかる（よりかかる）｜N1

- 品詞：五段・自動詞
- 意味：物に体重を預ける。比喩では、仕組みや人に強く頼る。
- 連語：壁に寄りかかる / 特定の機能に寄りかかる
- 記事文脈：テスト記事では、コードが特定の実行環境の振る舞いを前提にする意味です。
- 例文：特定のブラウザの挙動に寄りかかると、移行の際に思わぬ手間がかかります。
- 例文の意味：あるブラウザ特有の動きを前提にすると、移行に予想外の作業が必要になります。
- ニュアンス：技術の話では「依存する」に近く、頼り方を比喩的に描きます。

### 4. はっきり（はっきり）｜N5/N4

- 品詞：副詞
- 意味：物事の区別や意図が明確な様子。
- 連語：はっきり伝える / 違いがはっきりする
- 記事文脈：記事では代替テストで捕まえられない失敗が明確にあると述べます。
- 例文：代替で確認できる範囲を、レビューの最初にはっきり伝えます。
- 例文の意味：レビューを始めるときに、代替で分かる範囲を明確に説明します。
- ニュアンス：状態にも伝え方にも使えます。参考レベルはN4です。

### 5. 揺れる（ゆれる）｜N5/N4

- 品詞：一段・自動詞
- 意味：振動する。また、決まっていた状態が安定しなくなる。
- 連語：順序が揺れる / 気持ちが揺れる
- 記事文脈：記事では表示の順序がビルドごとに変わり得ることを表します。
- 例文：同じ日付の記事は識別子で並べ、表示の順序が揺れないようにします。
- 例文の意味：日付が同じ記事では識別子で並び順を決め、画面の順番を安定させます。
- ニュアンス：物理的な動きのほか、順序や判断の変動にも使えます。参考レベルはN4です。

### 6. 途絶える（とだえる）｜N2

- 品詞：一段・自動詞
- 意味：それまで続いていた流れが、途中で止まる。
- 連語：通信が途絶える / 記録が途絶える
- 記事文脈：監視の予約のかけ直しが来なくなる状況です。
- 例文：通信が途絶えた時刻を記録し、復帰までの時間を測ります。
- 例文の意味：通信が切れた時刻から、再びつながるまでの長さを調べます。
- ニュアンス：通信や連絡など、続いていたものが止まるときに使います。

### 7. 残す（のこす）｜N5/N4

- 品詞：五段・他動詞
- 意味：物や情報を、後から使えるようにそのままにする。
- 連語：証拠を残す / 経過を残す
- 記事文脈：原因を調べられるよう、停止時や復帰時の情報を保存します。
- 例文：測った値とそのときの条件を、後で読める形で残します。
- 例文の意味：測定値と条件を、後から参照できる形にして保存します。
- ニュアンス：記録の文脈では何を保存したかを「を」で示します。参考レベルはN4です。

## C-2. IT/AI専門用語

1. **CreationPolicy（作成ポリシー）**：指定数の成功通知を受けてから作成を完了させる条件。 EC2のuser dataの結果を待ちます。

2. **Elastic IP（固定パブリックIP）**：別のインスタンスへ関連付けを変更できる固定IP。 新しい台の準備後に関連付けを切り替えます。

3. **D1 prepared statement（D1の準備済み文）**：SQLを準備し、値を後から渡して実行する呼び出し。 代替で bind の引数を記録します。

4. **multipart upload（マルチパートアップロード）**：オブジェクトを分割して送り、受理済みのパートを確定する操作。 R2の代替で順序とパートの抜けを調べます。

5. **lightningcss（CSSの変換・圧縮器）**：CSSの構文を読み取り、変換や圧縮を行う処理系。 Astroのビルドで不正なセレクターを検出しました。

6. **exact match（完全一致）**：出力値が定義された正解と一致した場合を数える指標。 型を通った場合でも別に集計します。

## C-3. 新規文法

全96日分の既出用法と照合しました。原文の数量配分と時間間隔から、別々の働きを持つ新規文型2項目を選び、復習は別に扱います。

### 1. ～につき｜N2

- 意味：単位を一つ決めて、それぞれに割り当てる数量を表す。
- 形：数量名詞 ＋ につき ＋ 数量
- 用法：料金、上限、配布数などを説明する。
- 例文：作業者一人につき、一枚の入館証を用意します。
- 例文の意味：作業者それぞれに一枚ずつ入館証を準備します。
- 使い分け：ここでは「一人当たり」の意味です。「工事中につき」の原因用法とは接続後の働きが違います。

原文の形 「1台につき」 [Zenn](https://zenn.dev/miyakona/articles/ec2-replacement-waits-for-user-data)

### 2. ～ごとに｜N5/N4

- 意味：一定の区切りが来るたび、同じことを繰り返す。
- 形：時間・距離などの名詞 ＋ ごとに
- 用法：同じ幅の間隔を指定する場合に使う。
- 例文：五分ごとに、処理待ちの件数を集計します。
- 例文の意味：五分間隔で未処理の件数を数えます。
- 使い分け：時間の名詞に直接つながります。「時間が経つたびに」のような節を作らず間隔を示せます。参考レベルはN4です。

原文の形 「1秒ごとに」 [Zenn](https://zenn.dev/itaraiguma/articles/faulthandler-stall-watchdog-segfault)
