### 1. Corpus2Skillに近づけた「階層ナビゲーション型RAG」と、ベクトルDB版RAGを「どの段階で失敗したか」まで比べてみた

**原文：** https://zenn.dev/aiforall/articles/133752ce2d97ad

**公開日時：** 2026-11-25 11:35:47 JST

複数の資料を読まないと答えが出ないとき、似た文章を集める検索と、目次をたどり直せる検索に違いが出ます。著者はBedrockの130文書から40問を用意し、Corpus2Skillを参考にした仕組みとベクトルDB版を比較しました。86個の根拠箇所をもとに、文書への到達、根拠の保持、回答の判定を分けています。

判定を見直した後の正答率は、階層型の各方式で0.80から0.85、ベクトルDB版は約0.63でした。差が大きかったのは文書をまたぐ設問です。最後に読んだ5文書を8000文字までに絞る測り方では、先に取得した根拠を落としたように見える場合がありました。また、元は不正解だった84件を見直すと、文書にある補足を誤りとした例などが9件見つかりました。

ただし、文書数や設問数は限られ、工夫の効果と実行ごとのぶれをすべて分けられたわけではありません。今回のエージェント型は、一問あたりで費用が約15倍、応答時間が約7倍でした。正答率とともに、何を実際に読んで、いくらと何秒を使ったかを見て評価します。

**読む価値：** 根拠が渡らなかった場合と採点に問題があった場合を分ける手順を、実験結果と合わせて学べます。

### 2. Amazon API Gateway の API Portal で REST API の探索と管理 API への昇格を試してみた

**原文：** https://dev.classmethod.jp/articles/api-gateway-api-portal-discovery-managed-api/

**公開日時：** 2026-11-25 23:58:28 JST

自社のREST APIを管理対象に入れるまでを、著者が東京リージョンのAPI Portalで試しました。公開用と非公開用を作り、探索を開始して状態がRUNNINGになってから検証しています。インベントリの単位は、デプロイしたステージに属するメソッドとパスです。

およそ一分おきに確認すると、三回目に二つのAPIから計三項目が見つかりました。未管理の段階ではSHADOWで、公開か非公開かはそれぞれ別の表示でした。その後、各項目を管理APIにすると九つのセキュリティポスチャが取得できました。元のREST APIの設定と更新時刻を見比べても、テストで差はありませんでした。

ただし、数分で見えたのはこの一回の測定です。REST APIでも固定の定義と実際の通信を必要とする場合があり、HTTP APIやWebSocket APIには同じ確認方法を適用できません。管理に入れたことを設定変更と取り違えず、必要な修正があれば別に試します。

**読む価値：** 手元の一覧に載せるところから、管理の対象として情報を取得するところまでの段階が明確です。

### 3. Snowflake の CoCo for Excel を Microsoft 365 管理センターから組織配布して使ってみた

**原文：** https://dev.classmethod.jp/articles/cortex-code-for-excel-org-deployment/

**公開日時：** 2026-11-26 08:29:03 JST

Excelの横でSnowflakeのデータを扱えるCoCoのプレビューを、管理センターから配る試験です。著者はMicrosoft 365の検証テナントにXMLマニフェストを登録し、配布先の利用者を指定しました。接続ではSnowflake OAuthを使い、問い合わせに適用する権限は利用者側のロールで決まります。

まず自分だけに割り当て、約二時間後にExcelのウェブ版で表示を確認できました。接続後はデータを求め、書き込む前に出るプレビューを承認するとシートに表が入りました。対象外だった一般の利用者を割り当てに加え、アドインの表示とSSOでの接続も試しています。

ただし、二時間は確認した時点の値です。資料では反映まで最大72時間かかる場合があります。配布した人全員が同じデータを読めるわけでもありません。権限と情報の持ち出し方を確認し、表示・認証・シート書き込みを別の操作として試験します。

**読む価値：** 配布の成否だけでなく、利用者の画面とSnowflake側の権限がどうつながるか追えます。

### 4. AIが速く作っても人の待ちが残っていた —— 開発プロセス全体で減らした合意と、残した確認

**原文：** https://tech.smarthr.jp/entry/2026/11/25/182704

**公開日時：** 2026-11-25 18:27:04 JST

実装が早くなっても、作業の前後で人がそろうのを待てば、チームの時間は空きません。SmartHRの一週間スプリントのチームは、起票や詳細化にもAIを使い始め、フィーチャーリードに集まっていた準備を分担しました。担当者はチケットを完了まで持ち、リードはゴールと受け入れ条件を決めます。

減らした合意の代わりに、着手や完了の基準をリポジトリに置き、AIが参照できるようにしました。また、実装者と異なる人が設計意図やテストの証跡を見る手順を残しています。会議などを引いたチームの開発可能時間は週約69時間から約93時間になりましたが、一時間あたりの完了ストーリーポイントは両方とも約0.14でした。

ただし、計測はメンバー四、五人の取り組みで、作業の分け方も変えています。使える時間は増えましたが、品質への効果はまだ確かめられていません。今後は手戻りやレビュー側の負荷も観測すれば、待ちが別の場所に移っていないかを検討できます。

**読む価値：** どこで人が待っていたのかと、どの確認は残したのかが分かり、改善の測り方まで考えられます。

### 5. Kiro Mobile アプリがリリースされたので試してみた

### 1. 照らす（てらす）｜N2

- 品詞：五段他動詞
- 意味：この用法では、比較や判断の基準となるものと見比べる意味です。
- 連語：原文に照らす / 規定に照らして判断する / 事実に照らして考える
- 記事文脈：誤りとされた回答を、事前に決めた要点と元の文章で見直しています。
- 例文：判定に疑問があれば、回答を元の資料に照らして確かめます。
- 例文の意味：判定に納得できなければ、実際の資料を読み、答えを確かめます。
- ニュアンス：「見比べる」は対等な二つの対象にも使います。「原文に照らす」は原文を判断の基準として扱います。

### 2. 配る（くばる）｜N2

- 品詞：五段他動詞
- 意味：複数の受け手に物や情報を渡すことです。
- 連語：資料を配る / 参加者へ案内を配る / 利用者にアドインを配る
- 記事文脈：管理者が指定した利用者にOfficeのアドインを利用できるようにします。

### 3. 着手（ちゃくしゅ）｜N1

- 品詞：名詞・サ変自動詞
- 意味：仕事や課題の実行に取りかかることです。
- 連語：実装に着手する / 調査に着手する / 着手前に条件を確認する
- 記事文脈：記事では実装を始める前に、チケットの条件や作業の粒度を確かめています。
- 例文：仕様と確認方法が決まったので、担当者が実装に着手しました。
- 例文の意味：作るものと確かめ方の合意ができてから、担当者が実際に作り始めました。
- ニュアンス：「着工」は主に工事を始めることです。「着手」は開発や調査にも使えます。
