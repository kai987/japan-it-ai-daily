## C. 日本語学习｜JLPT + IT日本語

### C-1. JLPT 词汇（参考等级）

**N3**
- **管理（かんり・名/サ変）**：管理。例：Agentが利用できるModelを管理します。
- **確認（かくにん・名/サ変）**：确认。例：Productionで利用中のVersionを確認します。

**N2**
- **制御（せいぎょ・名/サ変）**：控制。例：ToolへのアクセスをPolicyで制御します。
- **検証（けんしょう・名/サ変）**：验证。例：Patch適用後にE2E Testで動作を検証します。
- **運用（うんよう・名/サ変）**：运行、运维。例：本番運用では監査ログが必要です。
- **影響（えいきょう・名/サ変）**：影响。例：脆弱性の影響範囲を確認します。

**N1**
- **把握（はあく・名/サ変）**：掌握。例：Tool DefinitionのToken量を把握します。
- **考慮（こうりょ・名/サ変）**：考虑。例：品質だけでなくContext Costも考慮します。
- **連携（れんけい・名/サ変）**：联动。例：SBOMと脆弱性情報を連携します。
- **絞り込む（しぼりこむ・動）**：筛选。例：自社に影響するCVEだけを絞り込みます。

### C-2. IT / AI 专业词汇

- **Agent Identity**：Agent 自身的身份、Owner、Permission 与生命周期。
- **Progressive Tool Discovery**：按当前 Task 逐步发现并公开需要的 Tool。
- **Context Cost**：Prompt、History、Tool Schema 等占用的上下文成本。
- **脆弱性トリアージ / Vulnerability Triage**：根据资产暴露和业务影响给漏洞排序。
- **回帰テスト（かいきテスト） / Regression Test**：Framework Patch 后确认既有功能没有被破坏。

### C-3. JLPT 语法（参考等级）

1. **～必要がある（N4）**：有必要……。例：Patch適用後に動作を確認する必要があります。
2. **～によって（N3）**：根据/通过……。例：Versionによって挙動が異なります。
3. **～だけでなく～も（N3/N2）**：不仅……也……。例：精度だけでなく、コストも評価します。
4. **～に応じて（N2）**：根据……。例：Taskに応じて必要なToolだけを公開します。
5. **～とは限らない（N2）**：未必……。例：Contextが長ければ性能が高くなるとは限りません。
