- 含义：难以看见、难以识别
- 搭配：原因が見えづらい / 見えづらい不具合 / 差が見えづらい
- 文章语境：类型断言与默认值让 GSI 的错误难以显现。
- 例句：既定値へのフォールバックが、不具合を見えづらくします。
- 例句译文：回退到默认值让缺陷难以显现。
- 语感区别：づらい偏向主观困难，不能说成逻辑上不可能发现。

### 12. 構造的（こうぞうてき）｜N2

- 词性：な形容詞
- 含义：由结构本身造成的
- 搭配：構造的な欠落 / 構造的に生じる / 構造的な問題
- 文章语境：amount 被投影配置排除，因此每次该路径都会缺失。
- 例句：GSI経由ではamountが構造的に欠落しています。
- 例句译文：在 GSI 路径中 amount 是结构性缺失。
- 语感区别：不是泛指复杂；应指出具体结构原因。

### 13. 無理やり（むりやり）｜N2

- 词性：副詞
- 含义：强行、不顾条件地硬套
- 搭配：無理やり当てはめる / 無理やり変える / 無理やり進める
- 文章语境：把不含 amount 的 GSI 数据硬套入完整记录类型。
- 例句：完全なレコード型を、GSIの応答へ無理やり当てはめてはいけません。
- 例句译文：不应把完整记录类型强行套在 GSI 响应上。
- 语感区别：口语色彩较强，技术评论中也可用来批评不合理处理。

### 14. 明細（めいさい）｜N2

- 词性：名詞
- 含义：按项目列出的详细信息
- 搭配：明細を確認する / 処理結果の明細 / 明細に表示する
- 文章语境：DLP 的 Blocked 统计可见，但文件标题未出现在明细。
- 例句：Blockedの件数は分かっても、明細にファイル名はありませんでした。
- 例句译文：能看到 Blocked 件数，但明细没有文件名。
- 语感区别：区别于概要，强调逐项信息；不保证所有字段可见。

### 15. 常に（つねに）｜N3

- 词性：副詞
- 含义：始终、总是
- 搭配：常に確認する / 常に既定値を返す / 常に同じ結果
- 文章语境：投影缺失路径会持续使用默认值，而不是偶发异常。
- 例句：射影に含まれない属性を読むと、常に既定値が選ばれます。
- 例句译文：读取未被投影的属性时，总会选用默认值。
- 语感区别：只有固定条件下才能断言常に，不能把案例推到所有 GSI。

## C-2. IT/AI 专业词汇

1. **reference token（参照トークン）**：指向保管秘密、与调用方身份绑定的引用信息，不是真实 API 密钥。 Passport 的 VPC/Vault 凭据非分发设计。

2. **GSI Projection（GSIの射影）**：决定索引保存和返回哪些表属性的配置。 INCLUDE 未包含 amount 导致读取路径缺失。

3. **Type Assertion（型アサート）**：告诉编译器按指定类型处理，不执行运行时校验。 as OrderItem 把错误的返回形状隐藏在类型假设中。

4. **DLP（データ損失防止）**：按敏感信息标签和策略控制数据使用或摄入。 Quick 中区分 Blocked、Warn 和其他同步错误。

5. **JP-CRIS（日本国内クロスリージョン推論）**：把模型推理路由限制在日本国内区域的推理配置。 NEC 以国内所在地要求选择，不能与 global 配置混淆。

6. **TPM（1分間のトークン数）**：每分钟可处理 token 的配额，影响模型容量规划。 NEC 用试点实测估算并验证容量。

7. **OAM-MIMO（軌道角運動量を使う空間多重）**：结合 OAM 模式与模式内空间复用的无线传输技术。 NTT 在室外 100m、最大 22 路条件下验证容量。

8. **SINR（信号対干渉雑音電力比）**：衡量目标信号相对干扰及噪声的比值。 NTT 官方补足原文用峰值搜索来校正天线轴偏移。

## C-3. 新学语法

已读取前49期四目录及92个文法身份。本次新语法1项“～はずなのに”，原文明确出现；虽为N3，能训练数据结果与预期的差异。其他确认的高阶文型多已学，复习由独立模块从当日正文补足，不把例文变体当新文法。

### 1. ～はずなのに｜N3

- 含义：按道理应该如此，却出现了相反结果。
- 结构：動詞普通形＋はずなのに／い形容詞＋はずなのに／な形容詞・名詞＋な／の＋はずなのに
- 用法：原文以已经写入 5000 为依据，指出却使用默认值 1000。先给预期的依据，再说意外结果；不能把主观愿望当成必然。
- 原文形态：入れたはずなのに
- 原文依据：[5000を入れたはずなのに、デフォルト値の1000が採用されています。](https://dev.classmethod.jp/articles/dynamodb-gsi-type-lie/)
- 独立例句：値を登録したはずなのに、画面には既定値が表示されました。
- 例句译文：按理已经登记了值，画面却显示了默认值。
- 注意：はず表示有依据的预期，なのに表示逆接；并不证明写入确实成功，仍要分别核对写入与读取路径。
