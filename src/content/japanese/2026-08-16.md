## C. 日本語学习｜JLPT + IT日本語

### C-1. JLPT 词汇（参考等级）

**N3**
- **共通（きょうつう・名/形動）**：共同、通用。例：Repository全体の共通RuleをRootに置きます。
- **変更（へんこう・名/サ変）**：变更。例：Agentごとに作業Directoryを変更します。

**N2**
- **範囲（はんい・名）**：范围。例：Contextの適用範囲をDirectory単位で分けます。
- **維持（いじ・名/サ変）**：维持。例：自動テストで品質を維持します。
- **防ぐ（ふせぐ・動）**：防止。例：worktreeで変更の競合を防ぎます。
- **統一（とういつ・名/サ変）**：统一。例：FormatterでCode Styleを統一します。

**N1**
- **適用（てきよう・名/サ変）**：适用。例：Frontend固有のRuleだけを適用します。
- **競合（きょうごう・名/サ変）**：冲突。例：複数SessionのFile変更が競合する可能性があります。
- **網羅（もうら・名/サ変）**：覆盖、囊括。例：Evaluationでは長時間Taskも網羅します。
- **伴う（ともなう・動）**：伴随。例：並列実行には調整コストが伴います。

### C-2. IT / AI 专业词汇

- **コンテキストのスコープ管理 / Context Scoping**：只加载当前代码区域需要的规则。
- **開発規約（かいはつきやく） / Development Convention**：Agent 与开发者共同遵守的项目规则。
- **自己修正ループ / Self-correction Loop**：Generate → Type Check/Test → Fix 的循环。
- **権限ガードレール / Permission Guardrail**：在 IAM 之外限制 Agent 行为的规则层。
- **作業環境の分離 / Workspace Isolation**：用 Worktree 等隔离并行 Session。

### C-3. JLPT 语法（参考等级）

1. **～ごとに（N3）**：每……。例：DirectoryごとにAGENTS.mdを配置します。
2. **～ことで（N3）**：通过……。例：型チェックを行うことで、Agentへ明確なFeedbackを返せます。
3. **～だけではなく（N3/N2）**：不只是……。例：生成速度だけではなく、検証可能性も重要です。
4. **～場合には（N2）**：在……情况下。例：複数Sessionを動かす場合には、worktreeを利用します。
5. **～に伴って（N1）**：随着……。例：Agent数の増加に伴って、Session Managementも重要になります。
