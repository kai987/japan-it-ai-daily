- 词性：動詞
- 含义：补写、添加文字或代码
- 搭配：説明を書き足す / 処理を書き足す
- 文章语境：文章区分自動生成的跨度属性与需要自己补写的记录。
- 例句：自動では残らない情報を、ログに書き足します。
- 例句译文：把不会自动留下的信息补写到日志中。
- 语感区别：强调在既有内容上追加，不是从头重写。

### 10. 副次的（ふくじてき）｜N1

- 例句译文：URL统一是整理缓存带来的附带效果。
- 语感区别：不等于“不重要”，只是相对于主要目的而言。

### 11. 緊密（きんみつ）｜N1

- 含义：紧密、联系密切
- 搭配：緊密な連携 / 緊密に協力する
- 文章语境：LINE 作者在实习感想中提到与开发以外成员的紧密协作。

- 语感区别：用于关系、合作与联系的密切程度。

### 12. 濃密（のうみつ）｜N1

- 词性：形容動詞
- 含义：浓密；内容或体验密度很高
- 搭配：濃密な時間 / 濃密な経験
- 文章语境：作者用这个词评价学习丰富的六周实习，不是性能数值。

- 语感区别：用于抽象体验时强调充实、密度高，而不是单纯时长。

### 13. 見届ける（みとどける）｜N1

- 词性：動詞
- 含义：亲眼确认事情发展到结果
- 搭配：結果を見届ける / 最後まで見届ける

- 例句译文：设置后确认运行直到最终结果。
- 语感区别：比“一眼看到”更强调跟踪到结束。

### 14. 惜しむ（おしむ）｜N2

- 搭配：努力を惜しまない / 別れを惜しむ

- 语感区别：否定形“惜しまない”通常是积极评价；也有惋惜离别等含义。

### 15. 助走（じょそう）｜N1

### 16. 載せる（のせる）｜N2

### 17. 入れ替える（いれかえる）｜N2

- 词性：動詞
- 含义：替换内部内容或交换位置

- 例句译文：测量前更换执行环境。

### 18. 判別（はんべつ）｜N1

- 含义：辨别、判定属于哪一种
- 搭配：種別を判別する / 境界を判別する
- 文章语境：原文说明带逗号字段直接拼接会使接收端无法辨别边界。

- 语感区别：与已学“見分ける”接近，但为不同汉字词；注意不是仅用同义换名重讲技术概念。

### 20. 難点（なんてん）｜N1

- 搭配：難点がある / 運用上の難点

- 例句译文：这种方式的困难点是必须分发到所有终端。
- 语感区别：可在承认优点后指出实际使用困难，不等于完全不能用。

## C-2. IT/AI 专业词汇

1. **CustomAttributes（カスタム属性）**：SageMaker 推理时原样传递的附加信息参数。 用于上下文传播时，需要长度检查与双方编解码约定。

2. **traceparent（トレースペアレント）**：W3C Trace Context 中携带追踪与父跨度身份的字段。 HTTP头能否进入目标容器须实测，不能从名字推断。

3. **queryKey（クエリキー）**：TanStack Query 用来识别查询数据的键。 归一化查询条件，避免同一结果拥有不同缓存身份。

4. **hydration（ハイドレーション）**：在浏览器把服务端输出与客户端运行状态连接的过程。 本文将服务端预取数据继承到初始查询缓存。

5. **SWR（ステイル・ホワイル・リバリデート）**：返回已有缓存并在后台重新验证的缓存方式。 LINE 增加的是服务端请求装饰器缓存，与每请求 QueryClient 分开。

6. **k6（ケーシックス）**：用脚本模拟负载并测量请求行为的工具。 本实验模拟资源获取，不把该时间当作浏览器LCP。

7. **Iceberg materialized view（アイスバーグのマテリアライズドビュー）**：以 Iceberg 保存已计算查询结果的物化视图。 Glue 管理型将数据与定义写入交给服务，刷新与读取仍是独立操作。

8. **managed-settings.json（マネージド設定ファイル）**：Kiro 安装客户端读取的端点策略配置文件。 本文测试 signin_method deny 规则，覆盖取决于分发和版本。
