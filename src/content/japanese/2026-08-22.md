## C. 日本語学习｜JLPT + IT日本語

### C-1. JLPT 词汇（参考等级）

**N3**
- **公開（こうかい・名/サ変）**：公开。例：Security Advisoryが公開されたら内容を確認します。
- **対応（たいおう・名/サ変）**：应对、支持。例：Patch公開後に速やかに対応します。

**N2**
- **影響（えいきょう・名/サ変）**：影响。例：Affected Versionの影響範囲を確認します。
- **防ぐ（ふせぐ・動）**：防止。例：Sandboxで危険なTool実行を防ぎます。
- **限定（げんてい・名/サ変）**：限定。例：検索対象を許可済みDomainに限定します。
- **保存（ほぞん・名/サ変）**：保存。例：ローカルへ保存しない要件を実挙動で確認します。

**N1**
- **偽装（ぎそう・名/サ変）**：伪装。例：Tool名やdescriptionが偽装される可能性があります。
- **適合（てきごう・名/サ変）**：符合。例：Compliance Requirementへの適合をTestします。
- **挙動（きょどう・名）**：行为、运行表现。例：CLIの実際の挙動をVersionごとに検証します。
- **供給（きょうきゅう・名/サ変）**：供应。例：PluginのSupply Chain Riskを管理します。

### C-2. IT / AI 专业词汇

- **Security Advisory**：厂商正式发布的漏洞影响与修复说明。
- **Agent Plugin**：将 Skill、MCP 配置等打包、跨 Agent Client 复用的扩展形式。
- **Tool Poisoning**：通过恶意 Tool Metadata 诱导 Agent 执行危险操作。
- **Domain / Date Filter**：控制 Web Search 来源与时效范围的过滤条件。
- **Conformance Test / 適合性検証**：验证实际行为是否满足 Security / Compliance Requirement。

### C-3. JLPT 语法（参考等级）

1. **～たら（N4）**：如果/之后。例：Advisoryが公開されたら、Affected Versionを確認します。
2. **～ために（N3）**：为了……。例：検索範囲を制御するためにDomain Filterを利用します。
3. **～ても（N3）**：即使……。例：終了コードが0でも、要件を満たしたとは限りません。
4. **～とは限らない（N2）**：未必……。例：Tool descriptionが実装内容と一致するとは限りません。
5. **～に基づいて（N2）**：基于……。例：正式なAdvisoryに基づいてPatch対応を判断します。
