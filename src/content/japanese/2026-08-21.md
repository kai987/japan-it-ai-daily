## C. 日本語学习｜JLPT + IT日本語

### C-1. JLPT 词汇（参考等级）

**N3**
- **一覧（いちらん・名）**：一览、清单。例：移行対象のFile一覧を先に作成します。
- **関係（かんけい・名）**：关系。例：Component同士の関係も確認します。

**N2**
- **漏れ（もれ・名）**：遗漏。例：仕様の移行漏れを自動的に検出します。
- **移行（いこう・名/サ変）**：迁移。例：Legacy Systemを段階的に移行します。
- **統合（とうごう・名/サ変）**：整合、集成。例：AIをCore Systemへ統合します。
- **共有（きょうゆう・名/サ変）**：共享。例：共通RuleをTeam全体で共有します。

**N1**
- **網羅性（もうらせい・名）**：覆盖完整性。例：入力の網羅性をCoverageとして可視化します。
- **欠落（けつらく・名/サ変）**：缺失。例：Data Modelの構造的な欠落を確認します。
- **漂流（ひょうりゅう・名/サ変）**：漂移；技术上常用于設定ドリフト。例：設定ドリフトを防ぐためSSOTを利用します。
- **再現性（さいげんせい・名）**：可复现性。例：新しいPCでも同じAgent設定を再現できる状態にします。

### C-2. IT / AI 专业词汇

- **Input Coverage**：应处理的输入中，Agent 实际处理了多少。
- **Data Model Completeness**：业务关系、约束是否完整表达在数据模型中。
- **Single Source of Truth / SSOT**：把共通 Agent 规则集中到唯一可信源。
- **Configuration Drift / 設定ドリフト**：多个 Agent 配置副本随时间不一致。
- **Workflow Integration**：把 AI 真正嵌入业务系统，而不是只作为旁路 Chat Tool。

### C-3. JLPT 语法（参考等级）

1. **～かどうか（N4/N3）**：是否……。例：すべてのFileを読んだかどうかを記録します。
2. **～だけではなく（N3/N2）**：不只是……。例：Componentの存在だけではなく、画面遷移も確認します。
3. **～た上で（N2）**：在……之后。例：対象一覧を確定した上で、Agentに処理させます。
4. **～ない限り（N2/N1）**：只要不……就……。例：Core Systemと統合しない限り、手作業は残り続けます。
5. **～にとどまらず（N1）**：不仅限于……。例：AIの品質問題はModelにとどまらず、Data Modelingにも関係します。
