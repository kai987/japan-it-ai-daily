## C. 日本語学习｜JLPT + IT日本語

> JLPT 等级均为学习参考。读音、词性与基本释义可参考 JMdict/EDICT；技术词不强行归入 JLPT。

### C-1. JLPT 词汇（参考等级）

**N3**
- **管理（かんり・名/サ変）**：管理。例：AIサービスの利用量を管理します。
- **確認（かくにん・名/サ変）**：确认。例：Agentの実行結果を確認します。

**N2**
- **検証（けんしょう・名/サ変）**：验证。例：検索結果の品質を実データで検証します。
- **運用（うんよう・名/サ変）**：运行、运维。例：本番運用では監査ログを残します。
- **削減（さくげん・名/サ変）**：削减。例：不要なContextを減らしてToken消費を削減します。
- **処理（しょり・名/サ変）**：处理。例：Local Modelで低レイテンシな処理を行います。

**N1**
- **把握（はあく・名/サ変）**：掌握。例：どのToolが実行されたかを把握します。
- **考慮（こうりょ・名/サ変）**：考虑。例：品質だけでなくコストも考慮します。
- **連携（れんけい・名/サ変）**：联动、集成。例：MCPを通じて外部Toolと連携します。
- **依存（いぞん・名/サ変）**：依赖。例：一つのCloud Modelだけに依存しない構成を検討します。

### C-2. IT / AI 专业词汇

- **可観測性（かかんそくせい） / Observability**：能追踪 Agent 的 Tool Call、状态和执行过程。
- **監査ログ（かんさログ） / Audit Log**：用于追责和故障调查的执行记录。
- **コンテキスト最適化 / Context Optimization**：只向模型提供当前任务真正需要的信息。
- **検索 / Retrieval**：在进入 LLM 推理前先找出相关文档或代码。
- **ハイブリッド構成 / Hybrid Architecture**：Cloud LLM 与 Local LLM 按场景组合使用。

### C-3. JLPT 语法（参考等级）

1. **～必要がある（N4）**：有必要……。例：Agentの実行履歴を保存する必要があります。
2. **～ために（N3）**：为了……。例：Token消費を減らすために、検索で対象ファイルを絞ります。
3. **～だけでなく～も（N3/N2）**：不仅……也……。例：精度だけでなく、コストも評価します。
4. **～に応じて（N2）**：根据……。例：機密性に応じてCloudとLocal Modelを使い分けます。
5. **～とは限らない（N2）**：未必……。例：Context Windowが大きければ性能が高くなるとは限りません。
