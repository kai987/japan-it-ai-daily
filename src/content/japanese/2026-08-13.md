## C. 日本語学习｜JLPT + IT日本語

> JLPT 等级为学习参考；专业技术词单独整理。

### C-1. JLPT 词汇（参考等级）

**N3**
- **設定（せってい・名/サ変）**：设置。例：Agentごとに利用可能なToolを設定します。
- **利用（りよう・名/サ変）**：使用。例：業務では必要なAI機能だけを利用します。

**N2**
- **制御（せいぎょ・名/サ変）**：控制。例：外部サービスへの接続を管理画面から制御します。
- **導入（どうにゅう・名/サ変）**：导入。例：AI Agentを段階的に社内へ導入します。
- **判断（はんだん・名/サ変）**：判断。例：RouterがTaskの難易度を判断します。
- **実行（じっこう・名/サ変）**：执行。例：危険なCommandは隔離環境で実行します。

**N1**
- **想定（そうてい・名/サ変）**：设想。例：本番利用を想定した権限設計が必要です。
- **伴う（ともなう・動）**：伴随。例：Agentの自律性向上には新しいSecurity Riskが伴います。
- **委ねる（ゆだねる・動）**：委托、交给。例：すべての判断をLLMに委ねるべきではありません。
- **損なう（そこなう・動）**：损害。例：過度な自動化が安全性を損なう可能性があります。

### C-2. IT / AI 专业词汇

- **権限管理（けんげんかんり） / Permission Management**：控制 Agent 可以执行的操作范围。
- **監査ログ（かんさログ） / Audit Log**：记录组织内 Agent 的执行轨迹。
- **モデルルーティング / Model Routing**：按任务难度、成本和性能选择模型。
- **サンドボックス / Sandbox**：隔离 Agent 的文件、网络和系统访问。
- **最小権限（さいしょうけんげん） / Least Privilege**：只授予完成任务所需的最低权限。

### C-3. JLPT 语法（参考等级）

1. **～に応じて（N2）**：根据……。例：Taskの難易度に応じてModelを切り替えます。
2. **～一方で（N2）**：另一方面。例：Agentは便利な一方で、権限管理が複雑になります。
3. **～に基づいて（N2）**：基于……。例：組織Policyに基づいてToolの利用を制御します。
4. **～ことができる（N4）**：能够……。例：Self-hosted環境ではアクセス範囲を限定することができます。
5. **～に伴って（N1）**：随着……。例：AI Agentの利用拡大に伴って、監査の重要性も高まります。
