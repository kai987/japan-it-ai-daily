## C. 日本語学习｜JLPT + IT日本語

### C-1. JLPT 词汇（参考等级）

**N3**
- **続ける（つづける・動）**：继续。例：Meeting終了後もCloud AgentがTaskを続けます。
- **戻る（もどる・動）**：返回。例：不確実な判定は人間のReviewへ戻します。

**N2**
- **共同（きょうどう・名/サ変）**：共同。例：Team Memberが同じAgent Sessionで共同作業します。
- **並列（へいれつ・名/形動）**：并行。例：複数Sessionを並列に実行します。
- **調査（ちょうさ・名/サ変）**：调查。例：Agentが障害原因を調査してIssueを作成します。
- **削減（さくげん・名/サ変）**：削减。例：Speculative Decodingで推論Latencyを削減します。

**N1**
- **委任（いにん・名/サ変）**：委托。例：低Riskな調査TaskをAgentへ委任します。
- **復元（ふくげん・名/サ変）**：恢复。例：Process再起動後もSessionを復元できる設計にします。
- **棲み分け（すみわけ・名）**：分工、划分。例：Agentと人間の責任を明確に棲み分けます。
- **定量化（ていりょうか・名/サ変）**：量化。例：AIの効果を工数削減などで定量化します。

### C-2. IT / AI 专业词汇

- **Cloud Agent Session**：在云端异步运行、可由团队继续补充 Context 的 Agent Session。
- **Speculative Decoding / 投機的デコーディング**：小 Draft Model 先预测，Target Model 批量验证 Token。
- **Capability Boundary**：只开放 Agent 当前业务需要的操作能力。
- **Long-running Session**：与终端 Process 生命周期解耦、可以长期持续的 Agent Task。
- **ROI / 投資対効果**：用工时、质量、产出等指标评价 AI 投资成果。

### C-3. JLPT 语法（参考等级）

1. **～ても（N3）**：即使……。例：Meetingが終わっても、Cloud AgentはTaskを続けられます。
2. **～ところまで（N3）**：直到……程度/阶段。例：Issueを作成するところまでAgentに任せます。
3. **～一方で（N2）**：另一方面。例：自動化は効率的な一方で、権限境界が重要です。
4. **～によって異なる（N2）**：因……而不同。例：Speculative Decodingの効果はHardwareによって異なります。
5. **～に応じて（N2）**：根据……。例：業務Riskに応じてAgentへ与えるCapabilityを変えます。
