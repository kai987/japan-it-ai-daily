- 词性：名詞
- 含义：对判断有多大把握的程度

- 文章语境：Jeff/Kev 新命题同为11/13，但错误问题不同。
- 例句：同率でも、誤った項目まで同じとは言えない。
- 例句译文：比率相同，也不能说错误项目相同。
- 语感区别：不同于同数：比率相同可以来自不同分母，须同时给样本数。

### 7. 混雑（こんざつ）｜N2

- 词性：名詞・サ変
- 含义：拥挤、请求集中导致繁忙
- 搭配：サーバーが混雑する / 混雑状況 / 混雑を避ける
- 文章语境：Clef 作者指出服务混杂影响响应时间。
- 例句：混雑の少ない一回だけでは、日常の速度は分からない。
- 例句译文：只测一次不繁忙时段，不足以判断日常速度。
- 语感区别：不同于負荷：負荷是处理负担，混雑强调请求等集中状态。

### 8. 隙間（すきま）｜N2

- 词性：名詞
- 含义：间隙，两个事物之间空着的部分
- 搭配：隙間を埋める / 隙間なく / 隙間がある
- 文章语境：Jeff 作者用GPU管线的隙間解释并发收益，这是机制推断。
- 例句：処理の隙間を埋めても、誤検知は別に測る。
- 例句译文：填补处理空隙后，仍须单独测误报。
- 语感区别：与切れ目不同：切れ目重中断点，隙間重空出的空间或时间。

### 9. 換算する（かんさんする）｜N2

- 词性：動詞・サ変
- 含义：按比例换成另一单位计算
- 搭配：円に換算する / 時間を換算する / 換算値
- 文章语境：Clef费用按美元换日元；Kev全量时间为换算，不是跑完测量。
- 例句：換算した時間を、完走の実測として書かない。
- 例句译文：不把换算时间写成完整运行实测。
- 语感区别：不同于測定或逆算：換算强调单位、规模之间的比例转换。

### 10. 採番する（さいばんする）｜IT/AI

- 词性：動詞・サ変
- 含义：按规则生成和分配编号
- 搭配：案件を採番する / 採番台帳 / 採番の規則
- 文章语境：dots 案件编号与Issue/PR编号独立。
- 例句：先に案件を採番してから、別の作業者へ依頼する。
- 例句译文：先给任务编好号，再委托其他执行者。
- 语感区别：枝番是主编号的细分，採番是生成并赋予编号的动作。

### 11. 着手する（ちゃくしゅする）｜N1

- 词性：動詞・サ変
- 含义：着手、开始具体开展某项工作
- 搭配：作業に着手する / 着手の確認 / 着手前
- 文章语境：dots 原文区分消息送出与工作者理解后开始执行。
- 例句：受付の返信だけでは、実装に着手したかは分からない。
- 例句译文：仅有接受回复，无法得知是否已开始实现。
- 语感区别：遂行是推进履行整个工作，着手聚焦开始这一时点。

### 12. 拮抗する（きっこうする）｜N1

- 词性：動詞・サ変
- 含义：力量相当、互相抗衡
- 搭配：実力が拮抗する / 拮抗した結果 / 二者が拮抗する
- 文章语境：Jeff/Kev 原文用拮抗形容新命题的相同正确率，不表示全任务相当。
- 例句：一つの課題で拮抗しても、別の出力型では差が出る。
- 例句译文：一个任务势均力敌，换输出类型仍可能有差。
- 语感区别：不同于競合：競合表示争用或竞争，拮抗进一步要求强度相近。

### 13. 四捨五入する（ししゃごにゅうする）｜N2

- 词性：動詞・サ変
- 含义：四舍五入，按后一位是否达5取整
- 搭配：期待値を四捨五入する / 小数を四捨五入する / 四捨五入した値
- 文章语境：Kev将概率期望换成整数评分；这与Jeff最大索引映射不同。
- 例句：四捨五入する前の値も、検証用に残した。
- 例句译文：也留下四舍五入前的值供核验。
- 语感区别：切り上げ是始终向上，切り捨て始终向下，四捨五入有边界规则。

### 14. 受け取る（うけとる）｜N3

- 词性：動詞・五段
- 含义：接收交来的物品、消息或产物
- 搭配：成果を受け取る / 通知を受け取る / 資料を受け取る
- 文章语境：dots案例的独立受取是收到产物后另做检验，未等于认可。
- 例句：成果を受け取ってから、受入条件に沿って確認した。
- 例句译文：收到产物之后，再按接受标准检查。
- 语感区别：受け入れる是认可或接受安排；这里受け取る只指产物到手，不代表批准。

### 15. 控えめ（ひかえめ）｜N2

- 词性：形容動詞
- 含义：克制的、程度偏低的
- 搭配：控えめな値 / 控えめに出す / 控えめな表現
- 文章语境：Clef对同值也输出较保守概率，因此旧阈值漏掉匹配。
- 例句：控えめな確率だからといって、すべて正しいとは言えない。
- 例句译文：概率比较保守，也不能说判断全都正确。
- 语感区别：不同于慎重：控えめ描述表达或量的少，慎重描述做事谨慎。

### 16. 古風（こふう）｜N1

- 词性：形容動詞
- 含义：古雅的，带有旧时代的风格
- 搭配：古風な表現 / 古風な言葉 / 古風な言い回し
- 文章语境：Jeff/Kev对白雪姫“身をやつす”这种古风表达有不同反应。
- 例句：古風な言い回しも、評価用の文に含めた。
- 例句译文：评测句子也加入古雅的表达。
- 语感区别：与時代遅れ不同：古風可以赞许旧时风格，不表示功能已过时。

### 17. 不向き（ふむき）｜N2

- 词性：形容動詞
- 含义：不适合，不符合某用途的要求
- 搭配：大量走査には不向き / 不向きな用途 / 用途に不向きだ
- 文章语境：Jeff/Kev附录讨论不同用途的局限，不能直接当实测绝对结论。
- 例句：速い処理でも、数値の評価には不向きかもしれない。
- 例句译文：处理虽快，也可能不适合数值评价。
- 语感区别：不同于不能：不向き是适合度的判断，未必表示功能完全不可实现。

### 18. 意外と（いがいと）｜N2

- 词性：副詞
- 含义：出乎预料地
- 搭配：意外と少ない / 意外と難しい / 意外と見つからない
- 文章语境：Snowflake 作者说官方文字有说明，但具体账户示例意外地少。
- 例句：具体例が意外と少ないので、引数の定義も確認した。
- 例句译文：具体例出乎意料地少，所以也核对了参数定义。
- 语感区别：属于口头自然用语；意外に较书面，不等于“実は”纠正事实。

### 19. 対称（たいしょう）｜N2

- 词性：名詞
- 含义：对称，两侧具有对应结构
- 搭配：対称な説明 / 対称にそろえる / 対称性を確認する
- 文章语境：Jeff/Kev新命题把两个选项写成对称的身份描述。
- 例句：二つの選択肢を対称な説明にして、語彙の偏りを減らす。
- 例句译文：把两个选项改成对称描述，减少措辞偏差。
- 语感区别：与同率不同：対称是表述结构，同率是结果比例；结构对称不保证结果相同。

### 20. 一概に（いちがいに）｜N2

- 词性：副詞
- 含义：一概地、无视条件差异统一断定
- 搭配：一概には言えない / 一概に決める / 一概に否定しない
- 文章语境：Clef原文因混杂和网络差异，不一概说某模型总更快。
- 例句：一回の測定から、一概に優劣を決められない。
- 例句译文：不能凭一次测量一概断定优劣。
- 语感区别：不同于一律に：一律描述统一处理规则；一概强调省略差异的笼统论断。

## C-2. IT/AI 专业词汇

1. **exact / semantic（完全一致／意味一致）**：分别检查字符相同与业务值相同。 Clef实验分母107与106，保留歧义日期。

2. **trigger filter group（起動条件グループ）**：按事件和条件筛选启动。 组内 AND、组间 OR。

3. **RE2 regular expression（RE2正規表現）**：Security Agent按完整名称匹配的正则。 通配符和正则语法不同。

4. **ACCOUNT_ROOT_BUDGET（アカウント予算オブジェクト）**：Snowflake账户全credit预算。 SQL设置额度与通知动作。

5. **ACTUAL / PROJECTED（実消費／予測消費）**：预算动作的触发基准。 原文实参ACTUAL，不能按注释写成预测。

6. **fixed commit（固定コミット）**：按不可变版本引用指令或产物。 dots固定指令、持续更新PROGRESS。

7. **Bucketed CUDA Graphs（長さ別CUDAグラフ）**：按输入长度分组预先捕获GPU执行图。 Jeff运行时具备优化，对照Kev不同。

8. **bool / choice / score（真偽／選択／数値評価）**：接口要求的三种输出类型。 Jeff的近似score不等于直接支持。

### 1. ～か否か｜N1

- 含义：是否……，以正式方式提出二择判断
- 结构：普通形＋か否か（名詞・ナ形容詞の肯定現在は、だを省くことが多い）
- 用法：书面语和技术判定中明确“成立或不成立”。原文用它限定是否隐瞒身份，避免被“秘密”等关联词牵走。
- 原文形态：隠蔽しているか否か
- 原文依据：[身分を偽り隠蔽しているか否か](https://zenn.dev/null_teck/articles/jeff-08b-vs-kev-08b-decision-models)
- 独立例句：指定した出力型へ対応しているか否かを、速度とは別に確認する。
- 例句译文：是否支持指定输出类型，须与速度分开确认。
- 注意：比かどうか正式；它只设定二择问题，不保证模型知道答案，也不消除需保留的未知。
