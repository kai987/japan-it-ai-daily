## C. 日本語学习｜JLPT + IT日本語

### C-1. JLPT 词汇（参考等级）

**N3**
- **安全（あんぜん・名/形動）**：安全。例：Agentを安全に利用するためのRuleを定義します。
- **直接（ちょくせつ・副/形動）**：直接。例：Promptだけで権限を直接制御することはできません。

**N2**
- **強制（きょうせい・名/サ変）**：强制。例：OS側でFile Accessを強制的に制限します。
- **記録（きろく・名/サ変）**：记录。例：Policy DecisionをAudit Logに記録します。
- **選択（せんたく・名/サ変）**：选择。例：MCPとDirect APIを要件に応じて選択します。
- **暗号化（あんごうか・名/サ変）**：加密。例：データを暗号化したまま処理します。

**N1**
- **境界（きょうかい・名）**：边界。例：Security BoundaryをModelの外側に置きます。
- **抑制（よくせい・名/サ変）**：抑制。例：Sandboxで誤操作の影響を抑制します。
- **追跡（ついせき・名/サ変）**：追踪。例：User操作とBackend Traceを追跡します。
- **担保（たんぽ・名/サ変）**：确保、担保。例：Runtime Policyで最低限の安全性を担保します。

### C-2. IT / AI 专业词汇

- **Runtime Enforcement**：由执行环境强制权限，而不是只依赖 Prompt。
- **Sandbox**：隔离 Agent 对文件、网络和进程的访问。
- **LLM Observability**：观察 AI 功能的使用状况、Trace 与异常。
- **Direct API Integration**：不通过 MCP，直接把外部 API 封装成 Tool。
- **Fully Homomorphic Encryption / 完全準同型暗号**：在数据保持加密状态时计算。

### C-3. JLPT 语法（参考等级）

1. **～だけでは（N3）**：仅靠……。例：Promptだけでは十分なSecurity Boundaryになりません。
2. **～ようにする（N3）**：设法使……。例：AgentがProject外へ書き込めないようにします。
3. **～に応じて（N2）**：根据……。例：AI Appの数に応じてMCP導入を判断します。
4. **～一方で（N2）**：另一方面。例：MCPは再利用しやすい一方で、運用コストも増えます。
5. **～にとどまらず（N1）**：不限于……。例：ObservabilityはInfrastructureにとどまらず、LLMにも広がっています。
