- term: Coverage Engineering
  japanese: Coverage Engineering
  meaning: 対象の集合を定め、処理や検証の抜けを調べる設計の考え方。
  context: 旧システムの仕様を分母にして、実装とテストの対応を確認します。
- term: Input Universe
  japanese: 入力対象集合
  meaning: 網羅性を判断するために先に定める対象全体。
  context: 学習上の整理語です。記事の画面・分岐・API・操作経路を、確認すべき全体として扱います。
- term: SSOT
  japanese: Single Source of Truth / 単一の正本
  meaning: 正しい情報の基準として管理する一つの情報源。
  context: 業務指標の定義やGitの永続ログで、どの情報を正本とするかが問題になります。
- term: Semantic Views
  japanese: セマンティックビュー
  meaning: 業務の指標やディメンション、関係を定義する論理的なビュー。
  context: Snowflakeは説明と検証済みクエリを添え、分析時の意味のずれを減らします。
- term: WAL
  japanese: 先行書き込みログ
  meaning: 変更を復元できるよう順序付きで残す先行書き込みログ。
  context: ContinuityではS3上のログを正本とし、ローカルリポジトリを再構成します。
- term: Git Infrastructure
  japanese: Git基盤
  meaning: Gitリポジトリの保存、転送、整合性を支える基盤。
  context: packfileをローカルに保ちながら永続化とレプリカの数を分けます。
- term: Monorepo
  japanese: モノレポ
  meaning: 複数の関連プロジェクトを一つのリポジトリで管理する構成。
  context: 大きなリポジトリへのCIの読み取り集中が、Gitの拡張性を求める背景です。
- term: ETag
  japanese: エンティティタグ
  meaning: 保存されたオブジェクトの状態を識別する値。
  context: Continuityは条件付きGETで索引が最新かを調べ、古ければ追い付きます。
