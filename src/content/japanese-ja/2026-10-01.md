# C. 日本語学習

## C-1. 新規JLPT語彙

過去50期とのidentity・活用形・意味照合後、原文に根拠のある新規20語を選びました。難易度は学習上の目安で、JLPTの公式語彙表ではありません。例文は条件を保った独自の学習用文です。

### 1. 収奪（しゅうだつ）｜N1

- 品詞：名詞・サ変動詞
- 意味：他者の資源や利益を奪い取ること。
- 連語：資源の収奪 / 収奪的な利用 / コスト収奪
- 記事文脈：異常なトークン消費をコスト収奪として扱っています。
- 例文：資源の収奪を防ぐため、利用量の異常を調べます。
- 例文の意味：普段とは違う大量利用がないかを確認します。
- ニュアンス：通常の取得と違い、他者の資源を奪う強い意味があります。

### 2. 偵察（ていさつ）｜N1

- 品詞：名詞・サ変動詞
- 意味：相手や対象の状況を探り、情報を集めること。
- 連語：偵察を行う / 偵察行動 / 偵察を検知する
- 記事文脈：基本検知の例に、乗っ取りと偵察が挙がっています。
- 例文：不審な偵察を見つけたら、対象の操作を追います。
- 例文の意味：攻撃につながる調査行動かどうかを確かめます。
- ニュアンス：単なる調査より、相手の状況を探る行動に焦点があります。

### 3. 見張る（みはる）｜N2

- 品詞：動詞・五段
- 意味：異常や不正がないか、注意して見続けること。
- 連語：動きを見張る / 内側から見張る / 入口を見張る
- 記事文脈：AWS環境を内側から見張る検知の仕組みとして説明されています。
- 例文：入口を見張るだけでなく、内部の操作も確認します。
- 例文の意味：外からの接続と、中で起きた行動の両方を見ます。
- ニュアンス：監視より日常的で、警戒して見続ける語感があります。

### 4. 素通り（すどおり）｜N2

- 品詞：名詞・サ変動詞
- 意味：途中で止まらず、そのまま通り抜けること。
- 連語：検査を素通りする / 素通りを防ぐ / 素通りしてしまう
- 記事文脈：Classicで一部の符号化した入力がそのまま通りました。
- 例文：検査を素通りした入力も、応答と一緒に記録します。
- 例文の意味：止められなかった例を、後から確認できるように残します。
- ニュアンス：通過したことを表し、被害が起きたことまでは意味しません。

### 5. 精緻（せいち）｜N1

- 品詞：名詞・形容動詞
- 意味：細部までよく考えられ、丁寧に作られていること。
- 連語：精緻な分類 / 精緻な設計 / より精緻になる
- 記事文脈：記事はStandardの分類モデルをより精緻だと解釈しています。
- 例文：分類が精緻でも、未知の入力は別に検証します。
- 例文の意味：細かい分類ができても、試していない入力への保証にはなりません。
- ニュアンス：正確という結果の評価と、細かく作られていることは分けます。

### 6. 棚卸し（たなおろし）｜N2

- 品詞：名詞・サ変動詞
- 意味：持っているものを一つずつ確かめ、全体を整理すること。
- 連語：画面の棚卸し / 資産を棚卸しする / 棚卸しを行う
- 記事文脈：遷移図の作成が、画面と到達経路の整理にも役立ちました。
- 例文：画面の棚卸しで、使われていない入口を見つけました。
- 例文の意味：今ある画面を整理し、利用されていないものも確認しました。
- ニュアンス：一覧を作るだけでなく、実在や用途を確かめる含みがあります。

### 7. 罫線（けいせん）｜N2

- 品詞：名詞
- 意味：区切りや位置合わせのために引く線。
- 連語：罫線を引く / 罫線を挟む / 罫線を消す
- 記事文脈：日本語コメントと実行行の間にASCIIの区切りを入れています。
- 例文：罫線を消しただけで、同じ不具合が再発しました。
- 例文の意味：区切りの行が対策の一部だったため、削除で問題が戻りました。
- ニュアンス：見た目の線でも、今回のように動作上の役割を持つ場合があります。

### 8. 巻き込む（まきこむ）｜N2

- 品詞：動詞・五段
- 意味：周りのものを一緒に取り込んだり、影響の中へ入れたりすること。
- 連語：改行を巻き込む / 周囲を巻き込む / 処理に巻き込む
- 記事文脈：コメント末尾のバイトが改行を取り込み、実行行まで影響しました。
- 例文：文字コードの違いが、次の行まで巻き込みました。
- 例文の意味：一行の読み取りの問題が、その次の命令にも及びました。
- ニュアンス：人を活動へ誘う意味もありますが、ここでは周囲への影響を表します。

### 9. 切れ目（きれめ）｜N2

- 品詞：名詞
- 意味：連続しているものが区切られるところ。
- 連語：バイトの切れ目 / 切れ目がずれる / 区切りの切れ目
- 記事文脈：文字コードの違いでバイトの区切りがずれました。
- 例文：切れ目がずれると、同じバイト列でも解釈が変わります。
- 例文の意味：どこまでを一文字とするかが変わり、読める内容も変わります。
- ニュアンス：処理の停止ではなく、連続したものの区切りを指します。

### 10. 行末（ぎょうまつ）｜N2

- 品詞：名詞
- 意味：文字の一行が終わる位置。
- 連語：行末のバイト / 行末に置く / 行末を確認する
- 記事文脈：問題が起きるかどうかはコメント末尾のバイトに左右されます。
- 例文：行末を確認すると、改行の直前に余ったバイトがありました。
- 例文の意味：行の終わりを調べることで、次の改行が消えた理由が分かりました。
- ニュアンス：ファイル全体の終わりや、改行そのものとは異なります。

### 11. 目印（めじるし）｜N2

- 品詞：名詞
- 意味：場所や性質を見分けるための印。
- 連語：目印を付ける / 目印にする / 文字コードの目印
- 記事文脈：BOMは読み取り側へ文字コードを知らせる印です。
- 例文：文字コードの目印がないと、別の方式として読まれることがあります。
- 例文の意味：読み手が適切な方式を選べない場合があります。
- ニュアンス：識別の印であり、認証や改ざん防止を保証するものではありません。

### 12. 透かし（すかし）｜N2

- 品詞：名詞
- 意味：紙や画像に重ねて見せる印や文字。
- 連語：透かし文字 / 透かしを入れる / 透かしが重なる
- 記事文脈：OCRが書類の透かしまで読み、数値に文字が混じりました。
- 例文：透かしが重なる数値は、原本と照合して確認します。
- 例文の意味：余計な文字だけでなく、元の数字が残っているかも見ます。
- ニュアンス：ここではOCRが読む重ね文字で、不可視の埋め込みを検証した例ではありません。

### 13. 致命的（ちめいてき）｜N2

- 品詞：形容動詞
- 意味：結果に取り返しのつかない大きな影響を与えるさま。
- 連語：致命的な問題 / 致命的な誤り / 致命的になりかねない
- 記事文脈：数値の使い方によって、部分的な読み違いが大きな問題になります。
- 例文：金額の符号の誤りは、後段の計算にとって致命的です。
- 例文の意味：一つの誤りでも、計算結果全体を大きく変える場合があります。
- ニュアンス：重大より強いため、どの結果を損なうのかを説明して使います。

### 14. 伴走（ばんそう）｜N1

- 例文：導入後も運用に伴走し、現場の課題を確かめます。
- 例文の意味：作って終わりにせず、利用中の問題にも継続して関わります。
- ニュアンス：相手の代わりに全部行うより、一緒に進み続ける意味です。

### 15. 早い者勝ち（はやいものがち）｜N2

### 16. 受け付ける（うけつける）｜N2

- 意味：申請や操作を受け取り、処理の対象にすること。

## C-2. IT/AI専門用語

1. **PromptInjection.Direct（直接プロンプトインジェクションのFinding）**：Guardrailsによる直接のプロンプト攻撃判定をGuardDutyが記録するFinding。 判定する役割と記録する役割を分けます。

2. **Cross-Region inference（リージョン間推論）**：処理がリージョンをまたいでルーティングされる仕組み。 Standardの処理先を、国内限定の要件と照合します。

3. **location.state（画面遷移で渡す状態）**：遷移時に次の画面へ渡す状態。 直リンクでは必要な選択状態がない画面がありました。

4. **Playwright（ブラウザ操作自動化）**：ブラウザを操作してクリックや撮影を自動化するツール。 今回の撮影は起動済みのローカルアプリで行っています。

5. **Miro REST API（MiroのHTTP操作API）**：スクリプトからボードの画像やテキスト、接続を作るAPI。 54枚を規則的に配置し、再実行できる形にしました。

6. **BOM（バイトオーダーマーク）**：ファイル先頭で文字コードなどを知らせるバイト列。 テンプレート全体でなく、書かれるスクリプトの先頭を確認します。

7. **CP932（日本語のコードページ）**：日本語Windowsで使う従来のコードページ。 UTF-8と区切り方が違うことが今回の原因です。

8. **ocrHighResolution（高解像度OCR機能）**：Azure AI Document Intelligenceの高解像度OCR機能。 小さい文字や符号を改善しても、透かしの混入が残りました。

9. **pypdf（PDF処理ライブラリ）**：PDFの既存テキストなどを読み取るライブラリ。 スキャン中心の入力では、テキスト抽出だけで対応できません。

10. **cloud.run（Cloud RunのカスタムURL用ドメイン）**：選んだ共有サブドメインをサービスへ対応付ける入口。 既定run.appの無効化とは独立しています。

## C-3. 新規文法

過去50期の四表現と93文法identityを照合しました。新規は原文にある名詞＋次第だの条件依存と、だけでの最小条件の2件です。後者はN3の実用例として選びました。既習文型は別の復習層で補い、例文を変えて新規件数を増やしません。

### 1. ～次第だ｜N2

- 意味：結果がある条件によって決まることを表します。
- 接続：名詞＋次第だ／次第で／次第なので
- 使い方：結果を左右する条件を示します。今回なら、改行が消えるかどうかを行末のバイトから説明します。
- 原文出現形：行末のバイト次第なので
- 原文根拠：[原因：どの行で起きるかは行末のバイト次第なので、コメントを書き換えると結果が変わります。](https://dev.classmethod.jp/articles/202609-windows-userdata-japanese-comment-parse-error/)
- 独自例文：改行が消えるかどうかは、行末のバイト次第です。
- 例文の意味：すべてのコメントで同じ結果になるのではなく、末尾の内容が影響します。
- 注意：動詞のます形＋次第の『すぐに』とは別の用法です。名詞につながり、依存する条件を表します。

### 2. ～だけで｜N3

- 意味：ある動作だけで結果につながることを表します。
- 接続：動詞辞書形＋だけで／名詞＋だけで
- 使い方：少ない操作で結果が変わることを説明します。機能を有効化した環境など、ほかの前提条件は消えません。
- 原文出現形：ClassicからStandardに切り替えるだけで
- 原文根拠：[まとめ：Content filters tierをClassicからStandardに切り替えるだけで、日本語DANとBase64の攻撃パターンをブロック。](https://dev.classmethod.jp/articles/guardduty-ai-protection-bedrock-guardrails-tier-verification/)
- 独自例文：設定を変えるだけで、今回の三つの入力は遮断されました。
- 例文の意味：その検証環境では、追加の実装をせずに結果が変わりました。
- 注意：N3の実用例として選んでいます。既習の『だけでなく』という追加とは働きが違います。すべての攻撃への保証にはしません。
