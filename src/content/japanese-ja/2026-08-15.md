technicalTerms:
- term: Agent Harness
  japanese: エージェント・ハーネス
  meaning: モデル、ツール、実行環境、セッションなどを組み合わせ、エージェントとして動かす基盤。
  context: DeepSeek HarnessはモデルやToolだけでなく、Sandbox、ファイルシステム、UIもPluginとして構成します。
- term: Prompt Injection
  japanese: プロンプトインジェクション
  meaning: 外部コンテンツに埋め込んだ指示で、モデルの処理やツール呼び出しを不正に誘導する攻撃。
  context: Webを読むAgentに不可視Unicodeや指示上書き文言が流れ込むと、攻撃者の指示を正規の指示と区別できない場合があります。
- term: Sub-agent
  japanese: サブエージェント
  meaning: 親エージェントから特定の仕事を委譲される補助的なエージェント。
  context: Claude Codeのforkは会話全体とプロンプトキャッシュを引き継ぎ、Sub-agentの作業を分担します。
- term: Context Isolation
  japanese: コンテキスト分離
  meaning: エージェントや処理ごとに、参照できる会話・データ・権限の範囲を分ける設計。
  context: 外部入力やSub-agentの作業を親セッションから分離し、影響範囲を限定します。
- term: Production-like Evaluation
  japanese: 実務評価
  meaning: 本番に近いデータ、手順、制約でモデルやエージェントを検証すること。
  context: Geminiのベンチマークだけでなく、実際の業務フローや失敗ケースを評価に含める考え方です。
- term: Guardrail
  japanese: ガードレール
  meaning: 危険な入力・操作・出力を検知または制限する安全機構。
  context: Tool Allowlist、Sandbox、Human Approvalなどを組み合わせ、Agentの逸脱を抑えます。
- term: Bedrock AgentCore
  japanese: Bedrock AgentCore
  meaning: AWS基盤上でAIエージェントのハーネス、ランタイム、ツール連携などを構築するマネージドサービス。
  context: ハンズオンではLambdaをAgentCore Gateway経由のToolとして接続し、CloudWatchアラームを確認します。
- term: Tool Allowlist
  japanese: Tool許可リスト
  meaning: エージェントが呼び出してよいツールをあらかじめ列挙した制御。
  context: Prompt Injection時にもファイル変更や任意コマンドへ到達しにくくする最小権限の防御層です。
