## A. 详细文字版

### 今日最值得看的 5 篇

1. **Copilot × Teams**：团队成员可以从 Teams 启动 Cloud Agent Session，但 Repository 权限和 PR Review 仍保留，说明 Agent Automation 不应绕开已有 Governance。
2. **Speculative Decoding**：LLM Latency 优化不只靠换小模型或量化，也可以从 Decode Algorithm 层优化。
3. **AIOps Capability Boundary**：Agent 可以调查日志和代码、自动建 Issue，但不一定应该自动修改和部署生产代码。
4. **Long-running Agent Runtime**：Session 状态与 CLI Process 分离后，需要管理 Owner、Workspace、Permission、Budget、TTL、Status 和 Audit。
5. **企业 AI 成熟度**：当 AI 从个人试用进入组织级使用后，难点转向内部人才、专家支持、Workflow Integration 和 ROI 定量化。

### 面接で使えるポイント

> Team向けCoding AgentでもRepository PermissionやCode Reviewを維持し、AI経由だからといって既存Governanceを迂回させないことが重要です。

> Long-running Agentでは、Sessionを単なるProcessではなく、状態、Workspace、Permission、Costを持つLifecycleとして管理する必要があります。

### 今日の技术主题：Long-running Agent Runtime

长期 Agent 的核心变化是 **Session ≠ Process**。Supervisor / Daemon 可以保存 Session State，让 Worker Process 重启后继续任务。优点是支持异步和并行工作；风险是 Concurrency、Workspace Isolation、Secrets、长期 Token / Tool Cost 和遗留 Session。Worktree 可以降低冲突，但不等于完整 Sandbox。

### 面试复习卡

- `Team Agentを導入するとき何を維持しますか。` → Repository Permission / Review / Approval。
- `Speculative Decodingとは何ですか。` → Draft Model / Target Validation / Latency。
- `Long-running Agentで何を管理しますか。` → Owner / Session / Workspace / TTL / Cost / Audit。

## B. 重点总结和面试可用的知识点

### GitHub Copilot × Teams
**中文：** Coding Agent 进入团队聊天环境后，仍然必须继承既有 Repository Permission 和 PR Governance。

**日本語：** Team向けCoding Agentでも、Repository PermissionとPull Request Reviewを維持することが重要です。

### Speculative Decoding
**中文：** 小型 Draft Model 先预测候选 Token，Target Model 批量验证，在不替换目标模型的情况下改善 Decode 性能。

**日本語：** Speculative DecodingではDraft Modelが候補Tokenを生成し、Target Modelがまとめて検証することでLatencyを改善できます。

### AWS DevOps Agent × GitHub MCP
**中文：** 高风险系统可以只让 Agent 自动调查和创建 Issue，把真实修复与部署责任保留给人。

**日本語：** AIOpsでは調査とIssue作成だけをAgentへ任せ、Code変更やProduction反映を人間に残す責任分界が有効です。

### Claude Code Supervisor
**中文：** 长期 Agent 需要独立 Session Management；Worktree 是并发隔离工具，但不能当作 Security Sandbox。

**日本語：** Long-running AgentではSession Managementが必要で、Git worktreeは競合回避には有効ですが完全なSecurity Sandboxではありません。

### Enterprise AI Talent / ROI
**中文：** AI 普及后，组织瓶颈从“不会开始”转为人才培养、专业支持和 ROI 量化。

**日本語：** AI導入が進むと、課題はTool選定から人材育成、専門家支援、ROIの定量評価へ移ります。
