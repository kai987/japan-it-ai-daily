## A. 详细文字版

### 今日最值得看的 5 篇

1. **Deterministic Workflow**：Agent 各阶段的状态迁移和审批不应完全由概率模型决定。State Machine 更容易 Test、Audit 和 Recover。
2. **Claude Code Reliability**：代理层、VPN、Prompt Cache、Masked Input 和 API Billing 都会影响真实企业使用体验。
3. **Prefill Router**：Router 可以利用模型内部状态预测任务难度，但学什么取决于 Label，应当像普通 ML 模型一样评价泛化能力。
4. **AI Cost Governance**：模型价格只是成本的一层，Context Size、Cache、Batch/Flex/Fast、Routing 与 Hard Limit 都需要统一管理。
5. **VLM Human Fallback**：业务判断不一定应该二值化，OK / REVIEW / NG 让不确定样本自然升级到人工复核。

### 面接で使えるポイント

> LLMに判断させる部分と、Workflow StateやApprovalのようにプログラムで決定的に制御する部分を分離することが重要だと思います。

> AI CostはModel Priceだけでなく、Context、Request数、Processing Mode、Budgetまで含めて管理する必要があります。

### 今日の技术主题：Deterministic Agent Orchestration

确定性 Agent Orchestration 的目标是让 **Workflow Engine 决定当前 Stage，Agent 只完成 Stage 内的推理或生成**。它提升 Reproducibility、Auditability 和测试能力，但复杂流程可能显得过重，而且长期 Agent Memory 仍需要整理和生命周期管理。

### 面试复习卡

- `Agent Workflowを全部LLMに任せない理由は何ですか。` → Non-determinism / State Machine / Audit。
- `LLM Routerは何を評価しますか。` → Label / Accuracy / OOD / Cost / Latency。
- `VLMで曖昧な結果をどう扱いますか。` → REVIEW / Human Escalation / Voting。

## B. 重点总结和面试可用的知识点

### AI-DLC v2
**中文：** Workflow State 由确定性引擎控制，可以让 Agent 更专注于具体子任务。

**日本語：** Workflow Stateを決定論的Engineで管理し、Agentは各StageのTaskに集中させる設計が有効です。

### Claude Code Reliability
**中文：** Coding Agent 可靠性不只看模型输出，还要监控 Network、Security Interaction、API Call 和 Billing。

**日本語：** Coding AgentのReliabilityには、Network、Permission UI、API Call、Billingも含まれます。

### Prefill Router
**中文：** Router 是独立 ML 系统，Training Label、真实业务数据和 OOD Evaluation 会决定实际价值。

**日本語：** LLM Routerも独立したML Systemとして、Label、実Workload、OODを評価する必要があります。

### GPT-5.6 Sol Cost Governance
**中文：** 成本治理需要结合价格、Context、Processing Mode、Usage 与 Budget Control。

**日本語：** AI Cost Managementでは、Model単価だけでなくContext、Processing Mode、Usage、Budgetを合わせて管理します。

### VLM Review Fallback
**中文：** 不确定样本不必强制 OK/NG，可以通过 REVIEW 状态保留 Human-in-the-Loop。

**日本語：** VLMの曖昧な結果はREVIEWとして人間へEscalationする設計が現実的です。
