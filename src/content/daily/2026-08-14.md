## A. 详细文字版

### 今日最值得看的 5 篇

1. **Local MCP Knowledge Layer**：相比把整个目录开放给 Agent，只暴露 overview、list、search、get 等只读 Tool，更容易控制 Context 和数据范围。
2. **Agent-friendly Framework**：AI Coding 的关键不只是“给 AI 更多文档”，而是让项目结构、类型系统和命令行工具能够机器验证 Agent 生成的代码。
3. **IAM Least Privilege**：自动 Role 可以降低开发门槛，但 Production 必须重新检查实际 API Permission，不能把宽权限模板直接长期使用。
4. **Human-in-the-Loop**：对评价标准、业务决策等高影响内容，AI 可以生成 Draft，但最终应由人确认。
5. **In-process QA**：当实现速度被 Agent 提升后，QA 如果仍留在最后阶段，会导致团队只是更快地产生需要返工的代码。

### 面接で使えるポイント

> MCPは外部APIを呼ぶだけでなく、必要な社内情報を安全に取得するContext Gatewayとしても利用できると思います。

> AIが生成したコードは、人間のレビューだけでなく、型チェック、静的解析、自動テスト、Security Auditで機械的に検証することが重要です。

### 今日の技術テーマ：Agent-friendly Software Architecture

Agent-friendly Architecture 的核心是 **Understand → Generate → Validate → Fix**。项目应提供明确 Convention、结构化 Context、Type Safety、Test、Audit 和机器可验证规则。优点是减少探索成本和 Hallucination；局限是验证规则本身可能不完整，因此 Automated Validation 不能替代 Human Review。

### 面试复习卡

- `AI生成コードの品質をどう保証しますか。` → Type Check / Static Analysis / Test / Audit。
- `MCPをKnowledge Searchに使うメリットは何ですか。` → Context削減 / Access Control / Reuse。
- `自動生成されたIAM Roleをそのまま本番で使えますか。` → Least Privilege / Review。

## B. 重点总结和面试可用的知识点

### Local MCP
**中文：** MCP 可以作为受控知识访问层，只让 Agent 在需要时读取相关信息，而不是开放完整文件系统。

**日本語：** MCPをKnowledge Access Layerとして利用し、Agentに必要な情報だけを安全に取得させることができます。

### Guren / Agent-friendly Framework
**中文：** 好的 Agent Framework 需要同时让 Agent 容易理解项目，也让机器容易验证生成结果。

**日本語：** AI Agent向けのFrameworkでは、Contextを明確にし、生成コードをType CheckやAuditで自動検証できることが重要です。

### IAM Role Manager
**中文：** 自动化配置提高便利性，但安全边界仍需要人工确认和 Production-specific Least Privilege。

**日本語：** 自動生成されたIAM Roleが最小権限とは限らないため、本番では必要な権限だけに絞る必要があります。

### Human-in-the-Loop
**中文：** 低风险任务可以更自动化，高影响任务则应保留明确的人类最终判断。

**日本語：** 重要な評価や意思決定では、AI Draftの後に人間が確認して反映するHuman-in-the-Loopが有効です。

### In-process QA
**中文：** AI 加速实现以后，QA、Requirement 和 Validation 也要前移，才能防止速度提升转化为返工增加。

**日本語：** AIで実装速度が上がるほど、QAやValidationを開発初期から組み込むことが重要です。
