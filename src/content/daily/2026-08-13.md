## A. 详细文字版

### 今日最值得看的 5 篇

1. **企业 AI 治理**：Coding Agent 能执行 Shell、读取文件和连接 MCP，因此企业需要比较权限、外部连接、监控和工作空间管理能力，而不只看模型 Benchmark。
2. **Model Routing**：一次 Agent 任务可能需要几十次模型调用，很多步骤只是读取、总结、检查，因此没有必要全部使用 Frontier Model。
3. **Self-hosted Runtime**：将 Agent 运行在 EC2、Container 或受控服务器中，可以限制 Repository、Network、Credential 和文件系统访问范围。
4. **Local / Open Model**：小型开放模型可以承担长期、重复和低风险工作，复杂推理再升级到强模型。
5. **Computer-using Agent**：Agent 开始操作 Gmail、CRM 和 Web App 后，Credential、Approval、Rollback 和 Audit 需要进入系统设计。

### 面接で使えるポイント

> AIコーディングエージェントを企業に導入する場合、モデル性能だけでなく、権限管理、監査ログ、外部接続、機密情報の保護を確認する必要があります。

> 複数のLLMを使う場合、Taskの難易度に応じてModel Routingを行い、品質を維持しながらコストを最適化する方法が有効だと思います。

### 今日の技術テーマ：Model Routing

Model Routing 是让 Router 根据 Task Complexity、Cost 和质量要求选择模型。它的优势是减少不必要的高价推理、降低 Latency 并提高多模型灵活性；难点是 Router 也可能误判，因此需要独立 Evaluation。

### 面试复习卡

- `企業でAI Agentを導入するとき何を確認しますか。` → 権限 / 監査 / 外部接続 / 機密情報。
- `なぜ全部のTaskにFrontier Modelを使わないのですか。` → Cost / Latency / Task Complexity。
- `Agentの実行環境を分離するメリットは何ですか。` → Blast Radius / Access Scope / Sandbox。

## B. 重点总结和面试可用的知识点

### 企业 AI Governance
**中文：** 组织管理能力决定 AI Agent 能否安全进入企业环境，管理员必须能够限制命令、文件、MCP 和外部连接。

**日本語：** 企業利用では、AI AgentのCommand、File Access、MCP、外部接続を組織側で制御できることが重要です。

### Model Routing
**中文：** Router 可以让低复杂度任务使用低成本模型，只在困难任务上调用高性能模型。

**日本語：** Taskの難易度に応じてModelを切り替えることで、品質とコストのバランスを改善できます。

### Self-hosted Agent Runtime
**中文：** Agent 应尽量运行在隔离的执行环境中，以限制能接触的 Credential、代码和系统资源。

**日本語：** AgentをEC2やContainerなど分離された実行環境で動かすことで、アクセス範囲と影響範囲を制御できます。

### Local/Open Model
**中文：** 本地开放模型适合大量简单、隐私敏感或长期运行任务，复杂任务再交给强模型。

**日本語：** Local Modelは大量の単純Taskや機密性の高い処理に利用し、複雑な推論のみ高性能Modelへ切り替える構成が有効です。

### Computer-using Agent
**中文：** 当 Agent 能登录和操作业务应用时，Human Approval、Credential Isolation 和 Audit 成为必要条件。

**日本語：** 業務Applicationを操作するAgentでは、認証情報、承認フロー、監査ログを明確に設計する必要があります。
