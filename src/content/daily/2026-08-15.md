## A. 详细文字版

### 今日最值得看的 5 篇

1. **DeepSeek Harness**：现代 Agent 不再只是 LLM + Prompt，而是由 Model、Tool、Skill、Sandbox、Session、Permission、Evaluation 等组成的完整运行系统。
2. **Prompt Injection**：Web、邮件、外部文件都属于 Untrusted Input。真正有效的防御不仅是识别恶意 Prompt，还要通过 Least Privilege、Sandbox、Tool Allowlist 和 Human Approval 限制影响范围。
3. **Claude Code Multi-agent**：Sub-agent Fork 和跨 Session 通信让并行开发更现实，但也增加 Context Isolation、Task Boundary 和成本管理问题。
4. **Gemini 3.7 Flash**：Benchmark 只能作为参考，企业应使用自己的 Coding / Agent Task 做 Evaluation。
5. **Bedrock AgentCore**：Agent Runtime/Harness 正成为与 Model 分离的独立技术层。

### 面接で使えるポイント

> AI Agentでは、Modelだけでなく、Tool、Runtime、Sandbox、Session、Permissionまで含めてSystemとして設計する必要があると考えています。

> Prompt Injection対策では、外部情報を信頼しないことに加えて、最小権限やSandboxで攻撃成功後の影響範囲を制限することが重要です。

### 今日の技術テーマ：Agent Harness

Agent Harness 是让模型真正“作为 Agent 运行”的基础层，负责 Tool Call、Session、Memory、Sandbox、Permission、Agent Loop 与 Evaluation。好处是 Model 与执行逻辑解耦，更易于测试和治理；代价是系统复杂度上升，需要同时处理 Tool Failure、Network Failure、Context Overflow、Cost 和 Recovery。

### 面试复习卡

- `Agent Harnessとは何ですか。` → Model / Tool / Runtime / Session / Permission。
- `Prompt Injectionにどう対策しますか。` → Untrusted Input / Sandbox / Least Privilege。
- `Multi-agentで重要なことは何ですか。` → Task Decomposition / Context Isolation / Evaluation。

## B. 重点总结和面试可用的知识点

### DeepSeek Harness
**中文：** Agent Harness 把模型、Tool、Sandbox、Session 和 Orchestration 分层，让模型更换不必重写整个 Agent 系统。

**日本語：** Agent Harnessは、Model、Tool、Sandbox、Session、Orchestrationを管理する実行基盤です。

### Prompt Injection
**中文：** Tool 权限越强，Prompt Injection 的 Blast Radius 越大，因此 Security Boundary 必须放在模型之外。

**日本語：** Toolを利用できるAgentでは、Prompt Injectionの影響範囲が大きいため、最小権限とSandboxが重要です。

### Multi-agent
**中文：** 多 Agent 的价值来自任务分解和并行处理，而不是简单增加 Agent 数量。

**日本語：** Multi-agentではAgent数よりも、適切なTask分割とContext分離が重要です。

### Gemini 3.7 Flash
**中文：** 新模型不能只看 Benchmark，应对真实业务任务做质量、延迟和成本的综合评价。

**日本語：** 新ModelはBenchmarkだけでなく、実務Taskで品質、Cost、Latencyを評価する必要があります。

### Bedrock AgentCore
**中文：** Model 与 Runtime 是不同层，Runtime 决定 Agent 如何调用 Tool、保存状态和连接外部系统。

**日本語：** Modelは推論を担当し、Agent RuntimeはTool実行、状態管理、外部連携を担当します。
