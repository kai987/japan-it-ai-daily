## A. 详细文字版

### 今日最值得看的 5 篇

1. **AI Usage Governance**：企业需要知道谁用了多少 ChatGPT / Claude、花了多少钱，并把 Usage 与业务价值联系起来。
2. **VS Code AI Feedback Loop**：IDE 逐渐把 Agent 对话、Browser Preview 和多模型选择统一起来，减少“生成 → 切工具 → 看结果 → 再改”的摩擦。
3. **AWS Transform**：Repository 级 Agent 可以执行 Analysis → Finding → Remediation → Build/Test → PR，显示 AI Coding 正进入技术债治理。
4. **Long Context**：大 Context 只是容量，不代表“全部塞进去”是最佳策略。无关信息、Latency、自动压缩和成本仍然需要设计。
5. **Human-in-the-Loop**：Approval 也是有限资源。低风险、易回滚动作可以自动化，高风险决策才需要人真正参与。

### 面接で使えるポイント

> 企業の生成AIコスト管理では、全体のAPI料金だけでなく、UserやTeam単位のUsageを可視化し、実際のBusiness Outcomeと結び付けて評価することが重要です。

> Context Windowが大きくても、すべての情報を入れるのではなく、検索や要約で必要なContextを選択することが重要だと思います。

### 今日の技术主题：AI Agent Resource Governance

AI Agent 需要治理的不只 Token，还包括 **Context Budget、Agent Time、User / Team Budget、Human Attention 和 Approval Level**。成熟的系统应具备 Visibility、Budget、Evaluation 与 Responsibility 四层。Cost Optimization 的目标不是单纯“更便宜”，而是让成本和任务成果建立可解释关系。

### 面试复习卡

- `企業で生成AIのコストをどう管理しますか。` → Usage Visibility / Budget / ROI。
- `Long ContextでもRAGが必要なのはなぜですか。` → Relevance / Noise / Cost / Latency。
- `Human-in-the-Loopをどう設計しますか。` → Risk / Rollback / Impact / Responsibility。

## B. 重点总结和面试可用的知识点

### AI FinOps
**中文：** AI 成本治理需要用户级 Usage、预算与 ROI，而不是只看总 API 账单。

**日本語：** AI Cost Managementでは、User・Team単位のUsageを可視化し、Business Outcomeと合わせて評価することが重要です。

### VS Code Feedback Loop
**中文：** AI Coding 的生产力取决于反馈闭环速度，Browser Preview 与 Agent 对话越接近，修正越快。

**日本語：** AI Codingでは、生成速度だけでなく、結果確認と修正までのFeedback Loopを短くすることが重要です。

### AWS Transform
**中文：** Agent 可以把技术债发现、自动修改和确定性 Build/Test 验证串成完整工程流程。

**日本語：** AI Agentは技術的負債のAnalysisからRemediation、Build/Test、PRまで一連のWorkflowを支援できます。

### Codex Long Context
**中文：** Context Window 是容量，不是设计策略；真正重要的是相关信息选择和自动压缩管理。

**日本語：** Long Contextを利用できても、必要な情報を選択するContext Engineeringは引き続き重要です。

### Human-in-the-Loop
**中文：** 不是所有动作都要人工批准，而应按失败影响、回滚难度和业务责任分级。

**日本語：** Human-in-the-Loopは全操作の承認ではなく、RiskやImpactに応じて人間の関与レベルを設計する考え方です。
